R code to visualize the functional activity of peripheral nerve afferents (microneurography) following inflammation.

These code files reproduce Figures 3 and 5 from the manuscript ["Rapid peripheral reprogramming of myelinated afferents contributes to human hyperalgesia"](https://www.biorxiv.org/content/10.64898/2026.02.05.703527v1.abstract).

1- Figure 3A is produced using the Heatmap.r file.  
2- Figure 3B is produced using the UMAP.r file.  
3- Figure 5F is produced using the UMAP_2.r file.
